# Dual-Port RAM

## What it is

A dual-port RAM module with an accompanying testbench.

## Why it matters

It demonstrates concurrent memory-access structure relevant to Harvard-style designs.

## How it's built

`dual_prot_ram.v` contains the RAM RTL and `dual_port_tb.v` is the testbench.

## How to run

Compile both files in ModelSim/Questa and simulate the testbench.
