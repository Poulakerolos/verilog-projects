# Clock Divider

## What it is

A parameterized clock-divider module with testbench.

## Why it matters

Clock division is a basic timing and frequency-management pattern in synchronous digital design.

## How it's built

`clock_divider.v` is verified by `tb_clock_divider.v`; `tb_clock_divider.vcd` is the retained waveform capture.

## How to run

Run `run.do` in ModelSim/Questa, or compile the design and testbench directly.
