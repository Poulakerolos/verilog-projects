# 4-bit ALU

## What it is

A Verilog 4-bit arithmetic and logic unit with a dedicated testbench.

## Why it matters

It provides a compact, testable datapath building block.

## How it's built

`alu.v` is the design and `aluTB.v` supplies stimulus.

## How to run

Compile both files in ModelSim/Questa and run the testbench.
