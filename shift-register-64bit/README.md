# 64-bit Arithmetic Shift Register

## What it is

A 64-bit arithmetic shift register with Verilog testbench and retained simulation screenshots.

## Why it matters

Arithmetic shifts preserve sign, a useful building block for signed datapaths.

## How it's built

The RTL is `arethmatic_shift_regester.v`; `arethmatic_shiftTB.v` drives verification. Screenshots are under `screenshots/`.

## How to run

Compile the design and testbench in ModelSim/Questa.
