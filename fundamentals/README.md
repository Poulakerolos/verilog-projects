# Digital-Design Fundamentals

## What it is

Grouped introductory FPGA exercises: a two-bit adder, four-bit counter with divider, 2:1 mux, and comparator with seven-segment output.

## Why it matters

These modules document the foundational combinational and sequential design work supporting the larger projects.

## How it's built

Each exercise remains in its original subfolder with its Verilog source files.

## How to run

Compile an individual exercise in a Verilog simulator or FPGA toolchain.
