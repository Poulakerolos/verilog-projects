# FSM Sequence Detectors

## What it is

Mealy and Moore sequence detectors in overlapping and non-overlapping variants.

## Why it matters

The set makes the latency and state-encoding trade-offs between Mealy and Moore machines concrete.

## How it's built

The Verilog modules are accompanied by a lab testbench and screenshots in `screenshots/`.

## How to run

Compile a detector module with the appropriate testbench in ModelSim/Questa.
